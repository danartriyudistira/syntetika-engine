# Syntetika Engine 0.1.6 — macOS (Apple Silicon)

Nota is the DAW host; openVJ rides in the bundle as the visual engine. 0.1.6 adds **20 genre
presets for the Drum Rack**.

## Install

1. Download `Syntetika-Engine-0.1.6-arm64.dmg`.
2. Open it and drag **Syntetika Engine** onto **Applications**.
3. Launch it. **This build is not notarized** (no Developer ID on the build machine): on first
   launch macOS may block it — right-click the app → **Open**, or allow it under
   System Settings → Privacy & Security → **Open Anyway**. This is only needed once.

Requires macOS 12 or newer on Apple Silicon (arm64).

## New in 0.1.6

- **Genre presets for the Drum Rack.** Browser → Instruments → Drum Rack → **Genres** now holds
  twenty one-click starting points: House, Techno, Tech House, Deep House, Hip-Hop, Trap, Drill,
  Drum & Bass, Breakbeat, Disco, Funk, Rock, Pop, Reggaeton, Latin, Afrobeat, Amapiano, Jazz,
  UK Garage and Lo-Fi.
- Each preset borrows the pads of a matching factory kit — the samples render once and are
  shared, so the presets add no sample library — and gives the rack that genre's **swing**,
  **humanize** and **FX space**: Kompakt for house and tech house, Bunker for techno, Volta for
  deep house, Crate for hip-hop, Neon for trap and drill, Breakline for drum & bass and
  breakbeat, Mirrorball for disco, Brass Room for rock, Lagoon for reggaeton / Afrobeat /
  Amapiano, Terra for Latin, Velvet for jazz, Shuffle for UK Garage, Cellar for Lo-Fi.
- **The same list is under Nota Rhythm**, which remembers the preset it holds. The base kits
  are unchanged and keep their own names; a rack names its genre preset again from its timing
  after loading.
- **A starting point, not a fixed arrangement.** Load the sound, add a MIDI clip, then use
  **Pattern → Random…** with the same genre for a matching pattern.

## Known limitations

- A genre preset does not create a MIDI clip or a pattern by itself; the Pattern tab's Random
  dialog does that.
- macOS Apple Silicon is the only tested target. The DMG is ad-hoc signed (see Install).
- The genre presets reuse the factory kits' sounds; they change timing and FX space, not the
  rendered one-shots.
