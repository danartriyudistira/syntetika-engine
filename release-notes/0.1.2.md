# Syntetika Engine 0.1.2 — macOS (Apple Silicon)

Nota is the DAW host; openVJ rides in the bundle as the visual engine. Session clips carry
visuals, and the DAW's transport, scene launches and master audio drive the picture.

## Install

1. Download `Syntetika-Engine-0.1.2-arm64.dmg`.
2. Open it and drag **Syntetika Engine** onto **Applications**.
3. Launch it. **This build is not notarized** (no Developer ID on the build machine): on first
   launch macOS may block it — right-click the app → **Open**, or allow it under
   System Settings → Privacy & Security → **Open Anyway**. This is only needed once.

Requires macOS 12 or newer on Apple Silicon (arm64).

## New in 0.1.2

- **New ink-industrial demo**: a 2:59 Session set at 105 BPM in F minor with three layers —
  DrumBrute (Volta rack), Model D-style detuned bass (Monolith Reese + Valve/Crush) and Kobol
  portamento lead. Scene Follow runs Intro → Drop 1 → Break → Drop 2 → Outro at 0:35, 1:12,
  2:05, 2:45 and 2:59.
- **`ink-kaleido` ISF shader**: an eight-fold monochrome ink kaleidoscope (interlocking rings,
  faceted shards, snake bands, central star, smoky paper, radial light and film grain) with a
  different composition per section. Three visual layers, five looks.
- **Visuals follow scene changes**: the bridge mirrors the engine's playing scene, so Follow
  Actions, controllers and scene changes launch/clear visuals too. UI launches are recorded so
  they are not retriggered.
- **Visual clips survive quit-save**: an empty layout-uid map during shutdown no longer orphans
  every clip on the next open.
- **Restart budget recovery**: the visual engine's restart budget refills after a healthy run
  (and on an explicit View start), so a few crashes no longer leave the visuals down until the
  app restarts. A startup crash loop is still capped at three restarts.
- **OpenVJ tab layout**: Undo/Redo, Replace/Remove and Speed now sit in the Transport card in a
  tidy 2×2 block; the source name moved into the Source card. Narrower labels, stretching
  combos and the effect Mix row remove clipped controls.
- **Shaders ship in the bundle**: `Contents/Resources/shaders` carries the Ghost Arcade pack
  and Syntetika's own shaders, so ISF clips work outside the development tree.
