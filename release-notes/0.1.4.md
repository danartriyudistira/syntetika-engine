# Syntetika Engine 0.1.4 — macOS (Apple Silicon)

Nota is the DAW host; openVJ rides in the bundle as the visual engine. 0.1.4 adds **Nota
Session decks**: pages of Session scenes that share all tracks, instruments, devices and the
mixer, with the visual side following every deck.

## Install

1. Download `Syntetika-Engine-0.1.4-arm64.dmg`.
2. Open it and drag **Syntetika Engine** onto **Applications**.
3. Launch it. **This build is not notarized** (no Developer ID on the build machine): on first
   launch macOS may block it — right-click the app → **Open**, or allow it under
   System Settings → Privacy & Security → **Open Anyway**. This is only needed once.

Requires macOS 12 or newer on Apple Silicon (arm64).

## New in 0.1.4

- **Session decks.** The deck bar sits under the Session grid: tabs on the left, **+ Deck** on
  the right, right-click a tab for Rename / Duplicate / Remove. A deck is a page of scene rows;
  tracks, instruments, devices, returns and the mixer are shared. Switching decks never stops
  a playing clip, and Follow Actions stay inside the open deck.
- **Visual decks follow Nota.** openVJ gets one deck per Nota deck, with one column per scene
  of that deck. Duplicate copies the visual deck, Remove drops it, switching a tab switches
  both sides. Clicking a deck tab in openVJ switches Nota's deck too (and vice versa). Deck
  structure edits stay in Nota (openVJ's deck add/remove/rename are disabled while hosted).
- **Triggers stay in sync across decks.** Engine scenes are global; openVJ columns belong to
  the open deck, so every clip/scene launch is mapped through the open deck: clip ↔ slot,
  scene ↔ column, deck ↔ deck. A column clicked in openVJ asks Nota to launch the matching
  scene (audio + picture on one quantum); a clip clicked in openVJ launches its audio and
  schedules its picture. A launch still queued when you leave a deck is dropped instead of
  firing on the new deck's same column.
- **New projects start with a blank picture.** New Project clears clips, effects, media,
  visual history and extra decks (the output resolution is kept). Opening a project without
  `visuals/composition.json` also loads blank instead of inheriting the previous project's
  effects.
- **Video and image clips reload with the project.** Opening a project — or switching to a
  deck — now loads the media behind every video/image clip, so a saved video is not a black
  slot after reopening.
- **Deck undo/redo** is reconciled with the visual deck list (by name, and by position for a
  rename), so the tabs cannot drift apart. The OpenVJ tab compares against the open deck's
  column, fixing deck-2 slots that sat at “Loading the visual”.
- **Project format v36** stores the deck partition and the open deck. A v35 file opens as a
  single deck with its audio and visuals unchanged. Projects saved by 0.1.4 use v36 and need
  0.1.4 or newer.

## Known limitations

- Undoing a **deck removal** restores the audio deck; its visual clips start empty.
- Follow/stop that happens while a deck is not open is reflected when that deck is opened
  again.
- Visual-only clips (no audio) are not resumed automatically when a deck is reopened.
- MCP/remote scene tools still address the global scene index.
- The DMG is ad-hoc signed (see Install).
