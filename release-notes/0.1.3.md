# Syntetika Engine 0.1.3 — macOS (Apple Silicon)

Nota is the DAW host; openVJ rides in the bundle as the visual engine. Session clips carry
visuals, and the DAW's transport, scene launches and master audio drive the picture.

## Install

1. Download `Syntetika-Engine-0.1.3-arm64.dmg`.
2. Open it and drag **Syntetika Engine** onto **Applications**.
3. Launch it. **This build is not notarized** (no Developer ID on the build machine): on first
   launch macOS may block it — right-click the app → **Open**, or allow it under
   System Settings → Privacy & Security → **Open Anyway**. This is only needed once.

Requires macOS 12 or newer on Apple Silicon (arm64).

## New in 0.1.3

- **Closing Visual Output no longer restarts the engine.** The hosted engine kept running on
  Slint's default event loop, which ends when the last visible window is hidden: closing the
  output killed the helper, Nota restarted it, and the new process reloaded the last saved
  composition — losing visuals assigned since the last save. Hosted engines now run
  `run_event_loop_until_quit()`; a hand-started openVJ still quits with its window. No more
  flicker, GPU restart or lost visual edits when you hide the picture.
- **Save confirms the visual write.** A save waits for the engine's acknowledgement before it
  reports success; if the visuals could not be written it says so instead of claiming a clean
  save.
- **Visuals live in the project's version history.** Every save records
  `visuals/composition.json`; the content-named media it uses are pinned by the versions that
  need them. Switching to an older version (or opening one as a copy) restores the matching
  audio **and** visuals. Media GC now runs from Nota with the whole history in view, so a save
  cannot delete a file an older version still needs.
- **Crash recovery includes the visuals.** The periodic snapshot copies the composition,
  layout and media. A recovered project comes back with its picture, and the media is placed
  durably before the snapshot is deleted, so playback and the next save keep working.
- **A deleted project is not resurrected as a shell.** If the bundle disappears while open,
  layout/quit-save writes are skipped instead of recreating a `visuals/`-only folder.
- **Recovery keeps Recent Projects clean.** The temporary crash snapshot is no longer listed;
  the real bundle is recorded after a restore.
- **Session footer**: **Stop All clips** now sits above **+ Scene**.
- **Reproducible demo.** `demo/project.json` plus `scripts/make-demo.sh` rebuild the Ink
  Industrial set from scratch; the visual generator no longer needs an existing composition to
  name its columns.

## Known limitations

- Versions recorded **before 0.1.3** do not carry visuals (they were saved without one). Opening
  one restores its audio and leaves the visuals you have on screen untouched, rather than
  deleting them.
- The DMG is ad-hoc signed (see Install).
- Projects are still `.nota` **folder bundles**; the single-file container discussed for a later
  release is not part of 0.1.3.
