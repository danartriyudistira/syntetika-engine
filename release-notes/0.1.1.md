# Syntetika Engine 0.1.1 — macOS (Apple Silicon)

Nota is the DAW host; openVJ rides in the bundle as the visual engine. Session clips carry
visuals, and the DAW's transport, launches and master audio drive the picture.

## Install

1. Download `Syntetika-Engine-0.1.1-arm64.dmg`.
2. Open it and drag **Syntetika Engine** onto **Applications**.
3. Launch it. **This build is not notarized** (no Developer ID on the build machine): on first
   launch macOS may block it — right-click the app → **Open**, or allow it under
   System Settings → Privacy & Security → **Open Anyway**. This is only needed once.

Requires macOS 12 or newer on Apple Silicon (arm64).

## New in 0.1.1

- **A/V offset and calibration**: View → A/V Offset… shifts every visual launch and the video
  phase by ±200 ms (positive delays the picture) and turns on a white beat strobe on the
  output. Drag until the flash lands on Nota's metronome click. The value is saved and
  replayed before the engine starts. The strobe only runs while the transport advances.
- **Unused media cleanup**: saving a project now prunes `visuals/media` files the composition
  no longer references (only after a successful save).
- **Smaller fixes from the feature audit**: the preview clears after an audition instead of
  keeping a stale frame, the slow-render log is rate-limited, and the video/OpenVJ strings go
  through the localization layer.

## Already in 0.1.0

- Session clips with visuals: launch, quantized start, phase/trim sync, copy/duplicate, and
  scene structure mirroring.
- Click a clip in openVJ and Nota launches the matching Session slot (audio + visual together).
- Drop a video on a visual slot: its sound joins that slot and both are beat-synced.
- Visual output window (always on top, 854×480; maximize = fullscreen, Esc/F restores).
- Visual performance profiles (Eco 30 / Balanced 45 / Quality 60).
- Audio-reactive visuals from Nota's master through a lock-free shared ring.
- Reconnect recovery and the slow-visual guard.
