# Syntetika Engine 0.1.5 — macOS (Apple Silicon)

Nota is the DAW host; openVJ rides in the bundle as the visual engine. 0.1.5 adds **one-file
`.syntetika` projects**, fixes **AI model downloads**, makes **audio → MIDI** controllable, and
adds **random drum patterns by genre**.

## Install

1. Download `Syntetika-Engine-0.1.5-arm64.dmg`.
2. Open it and drag **Syntetika Engine** onto **Applications**.
3. Launch it. **This build is not notarized** (no Developer ID on the build machine): on first
   launch macOS may block it — right-click the app → **Open**, or allow it under
   System Settings → Privacy & Security → **Open Anyway**. This is only needed once.

Requires macOS 12 or newer on Apple Silicon (arm64).

## New in 0.1.5

- **One-file projects (`.syntetika`).** A project can now be a single ZIP container holding the
  whole bundle: `project.json`, sidecars, samples, plug-in states, visuals, media and the
  version history. Opening extracts it to a working folder; Save writes the folder and packs it
  back atomically. New projects and Save As use the file, while legacy `.nota` folders still
  open through **File → Open Legacy .nota Folder…**, save as folders, and migrate to a container
  on Save As (the old folder stays as a backup). Recent Projects, the Projects browser, version
  switching and crash recovery know both forms.
- **AI model downloads work again.** The pinned ONNX Runtime archive on GitHub is gone (404).
  The runtime now comes from the immutable `Microsoft.ML.OnnxRuntime` 1.23.2 NuGet package —
  the same native libraries for every platform, with pinned size and SHA. The first model
  installs it as before, and download failures now reach the log, not only the status line.
- **Audio → MIDI has timing and density controls.** Melody / Harmony open an **Audio to MIDI**
  dialog: snap note starts (and optionally ends) to a straight or triplet grid, then thin the
  result with a minimum strength, a shortest note and a per-chord voice limit. The note
  cleanup also merges fragments, drops duplicates, trims same-pitch overlaps, suppresses weak
  harmonics and semitone ghosts, and keeps real chords. The grid defaults to the piano roll's
  Quantize step.
- **Random drum patterns by genre.** In the Drum Rack **Pattern** tab, **Random…** offers 20
  genre sketches (House, Techno, Hip-Hop, Trap, Drum & Bass, Breakbeat, Disco, Funk, Reggaeton,
  Afrobeat, Amapiano, Jazz, UK Garage, Lo-Fi and more). Pick a genre or blend two — step by step
  or alternating bars — set Density and Variation, then Replace the pad notes or fill empty
  steps. Open hats replace closed hats, ghost snares and phrase crashes are built in. The
  window is non-modal and stays open for another roll; **Generate** is one undo step.
- **Fixes.** Save As no longer appends a second `.syntetika`; the legacy-open command is
  registered (the app starts normally); container migration copies media and history and keeps
  recents clean; visual writes and quit-save no longer resurrect a deleted bundle.

## Known limitations

- macOS Apple Silicon is the only tested target. The DMG is ad-hoc signed (see Install).
- `.syntetika` projects are extracted on every open (no cache yet); history is included, so the
  file grows with the version history.
- AI stem/transcription quality depends on the model and the source; the Audio to MIDI dialog
  is the place to tune density and timing.
- Random patterns support two genres and a 16th-note grid; there is no audio preview in the
  dialog and no MCP tool for it yet.
- Legacy project format v36 needs 0.1.4 or newer. `.syntetika` containers need 0.1.5 or newer.
